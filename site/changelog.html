版本日志

从 v1.0.0 的单盘内核，到 v1.15.0 的硬化收口。每个已发布版本都有对应的 tag 与 GitHub Release。

当前最新发布：v1.15.0（2026-10-24）。

v1.15.02026-10-24硬化收口
  • AP / 账户：AP 匿名（策略与桶策略交集）、账户命名空间 v1、SourceVpc 来源证明、缓存 TTL/负缓存、无策略默认拒绝、旧 *-s3alias 回落、XFF hops/CIDR 信任链。
  • TLS / 加密：私钥 0600 强制、CA 双信任轮换、主监听器与出站客户端热加载；SSE-KMS 显式 CMK 与命名环轮换（旧版本保留解密）。
  • 数据面 / 作业：tier 流式搬运与恢复、Batch 每动作桶通知、M7 版本定向删除与元数据复制、Select Parquet、GC 二次快照、生命周期游标、AbortMPU。
  • Inventory：增量水位（节点本地）与跨账户目标（仅管理员可配置，运行期复核源/目标账户）。
  • Level B：BucketSetLifecycleV2 正确标记 feature level 2；快照、cutover 与 force-recover 对 level-2 数据 fail-closed。
  • 验证：M9 sync/stretch/recovery/rolling 78/59/133/65 PASS；M8 e2e PASS（4433s）；S3 全量 e2e 38 节 RC=0；库测试 268/150/152；Playwright 9/9。

GitHub Release · 验收记录：docs/superpowers/specs/2026-10-23-capability-gaps-acceptance.md §8–§11；完整配置与边界见 README。

v1.14.02026-10-23能力边界清零
  • S3：ListObjects v1；UploadPartCopy；ListMultipartUploads（集群并集）；GET/HEAD partNumber；多区间 Range 降级整对象与 HEAD Range；版本控制三态 / Suspended；noncurrent 生命周期；匿名 Principal；Put/GetObjectRetention 与控制台锁状态；s3:ObjectAccessed:* 事件。
  • TLS：监听器、witness、Raft/mesh、site/repl/tier 出站与 Kafka SASL/SSL 全链路；未配置 [tls] 时仍为明文。
  • M8：Inventory Parquet/Hive；tier 本地冷盘池与远端 GC；生命周期完整 Filter / Date / 多转换与控制台编辑器；Batch/Object Lambda WASM（olap-wasm）；AP DeleteObjects、-s3alias 与 SourceIp。
  • M9：Level B 滚动升级兼容窗口（wire/feature 头、feature_level 门控、成员预检、runbook 与 e2e 脚本）；数据面仍非滚动。
  • 安全：AP 授权/执行一致性、SourceIp fail-closed、匿名审计限速；验收 0 Critical，2 High 已修复复审。

GitHub Release · 验收记录：docs/superpowers/specs/2026-10-23-capability-gaps-acceptance.md；完整配置与边界见 README。

v1.13.12026-10-22灾备恢复与控制面加固
  • force recovery 在初始化后固化基线快照并清理日志，新 learner 从快照取得恢复行。
  • Raft RPC 增加 target node id 校验，B′ 复用旧 endpoint 时不再触发 openraft 日志回退 panic。
  • 转发的控制写与成员操作同样校验目标节点，stretch 配对身份改为镜像比较。
  • cutover dry-run 输出字段级冲突；raft/sync 指标补齐语义说明。
  • 11 表三端字段级 diff 与灾备 e2e 纳入验收。
