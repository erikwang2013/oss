当前最新发布：v1.20.1（2026-10-28）。

v1.20.12026-10-28补丁
  • 账户软字节配额（AC-2）：新增只读 GET /accounts/{id}/usage（当前版本对象字节和；分页；集群丢 peer 时 complete=false、头 partial）与独立配置路由 PUT /accounts/{id}/soft-quota（body 必填 soft_byte_quota: N|null）；新增 level-3 ControlCommand::AccountSetSoftQuota。软配额只告警不阻写，与旧 /quota 互不清空；旧节点无法解码新命令，混版窗口使用前需全集群升级。
  • 缩容 4→3 真进程 e2e：新增 tests/e2e_m3_shrink.sh，覆盖 maintenance → plan → apply/verify → commit 前 rollback → commit 写 topo v4 → 新配置读回 → 旧配置/退役节点 fail-closed；评审加固后用真实二进制 97 PASS / 0 FAIL / 0 SKIP。
  • v1.20.0 源码归档修复：v1.20.0 的 Cargo.lock 把依赖 either 误标为不存在的 1.20.0，导致从 tag 构建失败；v1.20.1 已恢复 1.19.0，并通过 cargo metadata --locked 与聚焦测试。请勿使用 v1.20.0 源码包。
  • 未交付：硬字节配额、对象数配额、web 账户/用量 UI、跨账户共享、canonicalization worker；M8 多节点运行时与 Level C 补丁线仍按原计划。
  • 兼容性：无破坏性配置变更；topo v4 语义不变；新增 level-3 命令变体，混版窗口内使用软配额配置前必须升级全部节点。

GitHub Release · README：README.md / README.en.md。

v1.20.02026-10-27Wave2 修复
  • DP-2 mesh 入站 TLS 热轮换：新增 Tls::mesh_server_watch() 与 xl-client::serve_tls_watch，每个入站连接取当前 rustls 配置（ALPN h2，1024 握手并发上限）；mTLS client-CA 对新连接生效，旧连接保持旧物料直到自然关闭。测试 tls_mesh_inbound 3 项。
  • 真实滚动 e2e：新增 tests/e2e_dproll.sh（3 节点同版本，A/B 数据 + C witness；PUT/GET/List V1/V2/MPU/版本删除；逐节点 TERM 重启；读不断、sync 写 503 fail-closed），最终树 116 PASS / 0 FAIL；tests/e2e_m9_rolling.sh 用 v1.13.1 旧二进制 64 PASS / 0 FAIL / 4 文档化 SKIP。
  • 账户写路径改走 Raft：7 个 level-3 ControlCommand（Create/Update/SetQuota/Delete/MemberAttach/MemberSetStatus/UserCreate），apply 按 username 自然键；accounts_api 写路由统一经 ControlPlane（standalone 与 Raft 同一事务）；follower 503 + leader hint；fresh Raft 启动原子写 accounts_canonical_v1；OSSCTL3 快照携带账户行。
  • 缩容 topology v4 + 离线 apply：.oss.sys/topo 升级 v4（set=/node=/slot=/epoch=/hash=，即使 set 0 也带 set= 使 v1.19 parser 拒启）；只在 cluster-shrink commit 写入，启动只校验 legacy 三元组不改写，commit 前可回退旧二进制；新增 apply/verify/commit/rollback（CRC32C、EC 重建、可续跑、receipt、commit 前重查 namespace、commit 后 rollback 拒绝）。
  • 评审修复：移除启动期 eager v2/v3→v4 升级（避免伪造 commit 与破坏回退）；/api/v1/cluster/status fingerprint 只读磁盘 topo；账户 API HTTP 400/404 文案兼容；Raft 模式下跳过滞后的本地前置检查。
  • 未交付：缩容 4→3 loopback e2e、单机→集群（仍为重新灌入）、M8 多节点运行时（lease/worker takeover）、Level C 补丁线 v1.13.2/CMK/三二进制 e2e、软字节配额与跨账户共享、AP 真实 PrivateLink 身份、tier 直读默认关闭。
  • 兼容性：无破坏性配置变更；topo v4 由旧二进制 fail-closed，commit 后不支持回退到 v1.19，仅支持 commit 前 rollback；OSSCTL3/level 3 环境仍不可回退到 v1.18 及更早。
