v1.27.02026-10-31分布式存储版
  • feature level 8：账户硬配额配置 AccountHardQuotaSet 与动态 VPC 端点注册表 VpcEndpointUpsert/VpcEndpointDelete 走 Raft；OSSCTL3 快照携带 vpc_endpoints，管理员 API 可列表/注册/删除。全 peer ≥8 才启用，旧节点单向门。
  • 跨版本 MPU：wire-1 属主走有界回退（预落盘、5 GiB 上限、MD5 与属主 ETag 核对，v1.16+）；裸 UUID 的 ListParts/Complete/Abort 归属发现与 Complete 幂等重放；≤v1.15 无 MPU RPC，明确不支持。
  • Level C / 升级语义：Ext 类型能力协商（x-oss-raft-ext-types、leader append 前按全体 voter/learner 宣告集拒绝、成员 preflight）；在途 MPU 计入 CMK 引用；CMK 激活为不归点，cmk rewrap 只能在同一 CMK 内升版本。
  • AP 端点身份：EndpointIdentityVerifier + trusted-proxy；attested-proxy 由可信网段内终止 mTLS/PrivateLink 的代理签 HS256 短期 JWT（vpce/vpc/account），服务端验签+时效+声明匹配，evidence 入审计。真实 AWS PrivateLink API/mTLS 证书→端点映射仍未实现。
  • Raft 存储：快照 >256 KiB 分块；日志 ≥1024 B 压缩为 z1:，连续 ≥256 条压成 raft_log_segment，读/truncate/purge 透明；写事务先读后写改 BEGIN IMMEDIATE。新日志格式单向，写后旧二进制不可读。
  • 运维：upgrade-preflight.sh --health-json/--require-no-mpu 强制 v1.16 数据面下限与 MPU 排空；blue-green-preflight.sh 只读蓝绿就绪闸门；oss-server --version；单机→集群 plan/resume/verify 工具。
  • 验证：fmt/clippy -D warnings；oss-server 265/0、xl-store 376/0/1、xl-s3 202/0；m8_ap_trust 18、raft_cutover 7、inventory 12、jobs 11、lifecycle 8、restore lease 3；脚本自检 109/0 与 78/0。
  • 仍未交付：任意双向混写、CMK→legacy 全量迁移、真实 AWS PrivateLink/mTLS 证书映射、≤v1.15 MPU、Raft 日志格式的 feature-level 门控。

v1.26.02026-10-31控制面版
  • M8 feature level 7：tier restore 后续状态（restored/清理/回滚）经 TierRestoreUpsert/TierRestoreDelete 复制，leader 切换不再丢在途 Restore 状态；schedule_lease 增加 acquire/renew/takeover（TTL 默认 30s，OSS_SCHEDULE_LEASE_SECS），调度器/清单/生命周期/tier sweep 统一走租约 fencing。全 peer ≥7 才启用，旧节点单向门；快照仍为 OSSCTL3，无迁移。
  • 账户硬配额：账户当前版本字节数与对象数上限，写入前原子预留、删除释放；跨节点用量按 30s 惰性/60s 采样聚合，对端不可达时只按已知下界拒绝（未知增量 fail-open），DB 错误 fail-closed。API PUT /accounts/{id}/hard-quota：standalone 直接写，Raft 模式暂返回 501；限额已写入后执行生效。
  • legacy 账户规范化 worker：serve 启动后 leader 门控补账户/成员行；standalone 单事务 + marker，Raft 复用 AccountCreate/AccountMemberAttach，不新增命令。
  • 流式 GET 批量读：远端 EC 分片按 OSS_SHARD_READ_BATCH_BYTES（默认 1 MiB，上限 16 MiB）一次读多块，减少 RPC；CRC32C、unit 解密与明文 SHA-256 不变。
  • 缓存/保留/审计：MPU 索引增加 TTL（默认 300s）并收敛 clean/加载竞态；0009 为 terminal_jobs_before 增加 (state, updated_at) 索引；/metrics 导出 oss_audit_dropped_total。
  • 桶复制：支持 Prefix/Tag/And 过滤器并回读归一化；复制体按 256 KiB 分块令牌桶限速，跨请求共享远端配额。Tag 规则不复制删除事件（无标签快照，已标 shortcut）。
  • 验证：fmt/clippy -D warnings 通过；xl-store 369/0、xl-s3 194/0、oss-server 248/0；复制 35、账户 12、3-voter restore/lease 3、observability 4；完整 workspace 见仓库记录。
  • 仍未交付：Raft 模式硬配额配置命令、tier restore 的 follower 立即清理（当前由 leader 收敛）、Level C 双向混写、跨版本 MPU、AP 动态 registry、真实 PrivateLink、单机→集群工具化。

v1.25.02026-10-31硬化版
  • 全对象 GET 流式直出：无 Range 的 GET 在 EC 形态按 64 KiB 块、旧 parts 按文件块直出；加密对象按 unit 解密（至多缓存一个 unit），内存不再随对象大小增长。逐片 CRC32C 与流末明文 SHA-256 终验；首字节前探测数据片，缺失回退受 OSS_MAX_BUFFERED_GET_BYTES 约束的重建；开流后缺失报错不跳字节。Range/partNumber 仍有界缓冲，CopyObject 源读取同样流式。
  • 列举键缓存与 MPU 索引：每节点按桶懒加载键集，每批 1024 键；OSS_KEY_CACHE_MAX_KEYS/OSS_KEY_CACHE_MAX_TOTAL_KEYS 默认各 200 万、OSS_KEY_CACHE_TTL_SECS 默认 300；超限回退逐页扫描。在途 MPU 索引按 create/abort/complete 增量维护，clean 回收暂存区后同步失效。
  • 分片并行写：同一块编码后的本地盘/远端 RPC 分片写并发执行，单片失败只作废该片，quorum 计数不变；断电注入测试保留逐片顺序路径。
  • 异步审计队列：有界 4096 行，单 worker 每 100 ms 或 256 行批量落库；队列满丢弃并计数（首次/每 1000 条告警），审计不阻塞请求。仅 serve 路径挂 worker，测试/离线命令保持同步直写。
  • feature level 6 JobPurge：终态作业按 OSS_JOB_RETENTION_DAYS（默认 30，0 关）由 leader 每小时分批清理；只删 done/error/cancelled 并同事务清 inventory/tier/parent 引用，queued/running/preempted 永不删除。全 peer ≥6 才可用，单向门。
  • 授权、DoS 与运维审计修复：补全 Select/加密/通知/复制/策略/ListBuckets 等 S3 操作授权映射；未映射操作与无桶会话 fail-closed；CopyObject 预 HEAD 上限；GET 条件与 TOCTOU 同 meta；登录体长度上限与 Argon2id 信号量卸载；列举上限；Docker secret 0700/0600、JWT 占位 fail-closed、compose 健康检查与环回端口；控制台懒路由与无限分页。
  • 验证：fmt/clippy -D warnings 通过；xl-store 363、xl-s3 189 + object_ops 57、oss-server 240 + 契约/审计/M8/Raft 套件全过；kill9 通过。
  • 仍未交付：tier restore 后续状态与 schedule lease/takeover、硬字节/对象数配额、真实 PrivateLink、AP 动态 registry（需 feature 7）、完整数据面滚动升级。
